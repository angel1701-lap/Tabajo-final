## 🎯 ¿Qué puedes hacer?

### 📊 Análisis de Ventas
- Ver métricas en tiempo real
- Identificar productos más vendidos
- Analizar tendencias mensuales
- Comparar ventas por marca

### 🔮 Predicciones
- Predecir ventas futuras (1-12 meses)
- Entrenar modelo con tus datos
- Ver métricas de precisión
- Visualizar predicciones

### 🏪 Gestión
- Buscar productos
- Ver detalles de ventas
- Filtrar por marca
- Consultar históricos

- **Backend**: Node.js, Express, MySQL
- **ML**: Python, Flask, scikit-learn
- **DevOps**: Docker, Docker Compose
